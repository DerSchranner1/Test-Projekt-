# Carport-Planer Zaunecke

Interaktive 3D-Planung für einen Carport auf der grauen Pflasterfläche an der Zaunecke,
mit Option Photovoltaik, Wallbox und Wechselrichter sowie einer Kostenschätzung.

- `index.html` im Browser öffnen (braucht Internet für three.js und Schriften).
- `carport-planer.html` ist dieselbe Seite ohne HTML-Gerüst (Quelle für das Artifact).
  Nach Änderungen `index.html` neu erzeugen: Gerüst + Inhalt von `carport-planer.html`.

Maße sind aus Fotos mit Meterstab geschätzt (± 0,5 m), Preise sind Richtwerte (brutto, Ende 2026).
